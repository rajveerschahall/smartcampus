# SmartCampus modules
Setup: `npm create vite@latest smartcampus -- --template react-ts`, then `npm i lucide-react`, install Tailwind (set `darkMode: "class"`), and copy `src/*` into your project.
Faculty Panel: manual attendance (Present/Absent/DL), duty leave approvals, faculty directory (16 teachers).
Event Portal: events from the 2026-27 academic calendar, with filters, register, team builder.
